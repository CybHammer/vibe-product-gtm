# 项目专属 Agent 提示词交付

完整推广包不仅交付一批现成案例，还要让产品项目中的 Agent 能继续生成更多图文和短视频。为每个产品生成一份独立的 `产品名-Agent内容创作提示词.md`，并在 HTML 报告最后增加“Agent提示词”章节。

## 放置说明

在完整提示词上方明确写清：

1. 首选做法是把提示词追加到实际产品项目根目录的 `AGENTS.md`，放在独立的“内容宣发 Agent”章节下；已有 `AGENTS.md` 时只能追加，不能覆盖原有工程、设计或安全规则。
2. 若所用 Agent 不会自动读取 `AGENTS.md`，把独立 MD 放在产品项目的 `docs/` 或项目根目录，并在每次创作任务开头要求 Agent 先完整读取。
3. 对支持项目知识库的对话式 Agent，把该 MD 上传为项目文件或知识文件。

报告中的说明要直接回答“这一段提示词放在哪里”，不能只写“复制使用”。

## 提示词必须包含

- Agent 的角色与唯一目标：持续制作面向潜在客户或实际使用者的获客图文和短视频，不扩展到日历、运营、投放、指标或复盘。
- 默认接受开发者关于产品有意义、有目标用户并值得继续宣发的判断；不得重新进行产品价值判断、需求验证、PMF 评估或项目劝退，也不得使用“没人会用”“没有意义”“不值得继续”等结论否定项目。
- 已确认的产品事实、核心亮点、可见结果和能力边界。
- 国内/海外、ToC/ToB 主路线、主要受众与平台优先级。
- 本项目内容池的分类、数量或选题来源；要求优先选择尚未做成案例的角度并避免重复。
- 自媒体标题标准：目标人物、熟悉痛点、真实动作、数字、冲突、悬念或可见结果；标题承诺必须被正文和画面兑现。
- 图文输出格式：标题候选、2:3 封面、逐页结构、每页文案与画面、完整正文、描述、Tags 和产品出现方式。
- 短视频输出格式：标题候选、9:16、开头钩子、逐镜头时间轴、画面、口播/对白、屏幕文字、完整配文、Tags 和封面。
- 平台适配规则：国内平台使用原生中文；海外内容必须本地化，不直接翻译中文标题和家长话术。
- 事实与证据边界：不得虚构功能、案例、评价、学习效果、数据、用户反应或商业结果；信息不足时只标记宣发素材缺口并提出所需材料，不把缺口解释成产品价值问题。
- 默认不写开发故事；只有用户明确要求开发者内容时才单独生成。
- 生成前检查、生成后自检和可直接调用的示例指令。

## HTML 章节

“Agent提示词”放在海外平台章节之后、最终总结之前，并加入导航。章节至少包含：

- 放置位置说明。
- 这份提示词能继续完成什么任务。
- 项目事实和内容规则摘要。
- 完整提示词正文或清晰的结构化预览。
- “复制完整提示词”按钮。
- 打开或下载独立 MD 的入口。

章节视觉沿用报告现有 `DESIGN.md`，不要为提示词另造一套 UI。

## 文件命名与完整性

- 默认文件名：`产品名-Agent内容创作提示词.md`。
- 提示词必须是当前产品专属内容，不能只给一个带占位符的通用模板。
- 独立 MD 与 HTML 中显示的产品事实、数量、平台和输出格式必须一致。
- 现成图文和视频案例只是起点；提示词应允许按任意合理数量继续扩写，同时要求去重、证据一致和平台原生表达。
