# 短视频推广制作手册

这个参考文件用于把产品亮点、客户问题、用户案例和教程变成完整短视频脚本与分镜。

## 一、短视频形式

### 1. 屏幕演示加口播

适合界面操作和结果变化明显的产品。

画面包括：输入、点击或操作、处理中间状态、最终结果、结果细节。

### 2. 客户问题口播加产品画面

适合购买顾虑、使用疑问、产品差异和选择观点。

口播直接回应潜在客户，产品截图、使用过程和结果画面作为证据镜头。

### 3. 使用前后对比

用两个明显状态建立反差，再补产品操作过程。

### 4. 选择指南

从潜在客户常见顾虑开始，用真实产品画面回答适不适合、练什么、答错怎么办和与替代方案有什么不同。

### 5. 用户案例

以人物的任务为主线，产品界面和结果作为主要证据画面。

### 6. 教程

只完成一个具体任务，不在一条视频里塞入所有功能。

### 7. 挑战或测试

先提出一个明确任务，再连续展示产品能否完成以及最后结果。

## 二、视频结构

常用20到60秒结构：

1. `0–3秒`：结果、客户问题、使用者挑战或一句冲突。
2. `3–10秒`：人物和任务。
3. `10–35秒`：产品动作或完整使用过程。
4. `35–50秒`：结果和细节。
5. 结尾：一句产品说明或适用人群总结。

时长可以变化，但前面承诺的内容必须在视频中真正出现。

## 三、开头方向

每条视频至少给三个开头：

### 结果先出现

先展示最终结果，再回到产品过程。

### 麻烦先出现

先展示用户正在经历的具体问题。

### 选择冲突先出现

先展示潜在客户正在比较的两种做法或一个真实顾虑。

### 具体任务先出现

直接提出“用这个产品完成某件事”。

### 用户场景先出现

用人物、职业和当时的任务进入产品。

## 四、国内自媒体标题

国内短视频标题不能停留在产品说明书层面。每条视频至少给五个标题候选，并让五个标题分别从不同方向切入：

- 具体动作：观众能看见人或产品正在做什么。
- 数字细节：使用产品中真实存在的数量、时间、步骤、题目或结果。
- 反差冲突：第一版和当前版、预期和实际、好看与可用之间的真实矛盾。
- 悬念结果：先给观众一个必须看画面才能回答的问题。
- 人物视角：创作者、用户、家长、岗位或团队在具体时刻的真实反应。

一个标题优先具备其中两项，并明确与目标客户或实际使用者的关系。五个候选全部都要达到可直接发布标准。数字只能来自产品材料、实测或脚本中的真实动作。

弱标题：

- `儿童数学游戏完整玩法`
- `AI 工具功能演示`
- `我的产品开发记录`

更合适的标题：

- `我把 7×8 做成一条雪道，孩子必须在撞上前选方向`
- `这个宝箱没有钥匙，答对 46+27 才会打开`
- `答案明明放大了，孩子还是看不清，我最后改了整条赛道`

标题可以抓人，但不能使用空洞的“震惊、炸裂、封神、颠覆”，不能虚构用户效果，也不能承诺脚本中没有出现的结果。

## 五、产品亮点视频

结构：

```text
结果预览
输入材料
用户原来的麻烦
产品关键操作
完整结果
放大一个细节
产品名称和用途
```

需要准备：完整录屏、局部放大录屏、输入、输出、前后对比、封面截图。

## 六、购买顾虑视频

结构：

```text
目标客户的具体顾虑
不合适的常见做法
产品中的真实处理方式
一段完整使用画面
结果和适用边界
自然说明产品
```

不要只放代码、键盘和咖啡，要让产品变化成为主画面。

## 七、用户案例视频

结构：

```text
人物和任务
原来的做法
最麻烦的步骤
开始使用产品
产品中的关键动作
结果出现
结果怎样被继续使用
```

没有人物出镜素材时，可以使用口播、产品录屏、输入材料和结果画面完成。

## 八、创始人实测视频

创始人选择一个自己会遇到的任务：

1. 展示原始材料。
2. 说明为什么要处理。
3. 开始使用产品。
4. 保留过程中值得看的画面。
5. 展示结果。
6. 指出满意和仍想修改的细节。

## 九、教程视频

教程只讲一个任务：

- 准备什么。
- 第一步做什么。
- 第二步做什么。
- 哪一步最容易出错。
- 最终结果在哪里。
- 结果还可以怎样使用。

## 十、分镜卡

每个镜头写清：

```text
时间：
画面：
口播：
屏幕文字：
产品操作：
需要的素材：
```

## 十一、完整短视频卡

每套视频方案交付：

```text
视频角度：
目标人物和场景：
建议时长：
三个开头：
选用的开头：
完整口播或对白：
逐镜头分镜：
产品录屏清单：
输入和结果素材：
屏幕文字：
结果出现的镜头：
结尾产品说明：
封面主题：
五个国内自媒体标题；海外内容则提供三个平台原生标题：
一句内容描述：
完整视频配文：
标签 Tags：
短版剪辑方案：
无口播版本：
```

内容描述用于一句话说明“这条视频给谁看、展示什么具体内容”。完整视频配文负责补充画面中来不及解释的事实。Tags 默认提供六到十二个，组合受众、场景、品类、产品形态和本条主题；不使用与内容无关的热门标签，不把同一组标签机械复制到所有平台。

## 十二、八套短视频的内容分布

完整推广方案默认从以下类型中选择八套：

- 一条核心产品演示。
- 一条使用前后对比。
- 一条完整教程。
- 一条购买选择指南。
- 一条用户案例、创始人实测或样例任务。
- 一条产品观点、对比、疑问或更新。
- 一条实际使用者挑战或体验。
- 一条题库、内容范围或适龄说明。

八条视频共享产品素材，但开头、叙事和核心画面要有明显区别。

完整推广方案中的八条都必须提供完整口播或对白、逐镜头分镜、屏幕文字、五个国内标题或三个海外标题、内容描述、完整配文和 Tags。八条都要面向潜在客户或实际使用者，不混入开发故事；不能只把前两条写完整。

## 十三、录屏和画面准备

- 先录制一遍完整流程。
- 再单独录制关键点击和结果细节。
- 准备竖屏裁切时仍能看清的界面。
- 把通知、账号信息和无关窗口隐藏。
- 为前后对比保留相同尺寸的素材。
- 旧版本和新版本分别录制。
- 创始人口播和产品画面分别录制，方便重新组合。
