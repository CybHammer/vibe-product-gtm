# 图文推广制作手册

这个参考文件用于把推广角度变成完整图文内容，包括标题、封面、页序、截图、说明图和正文。

## 一、图文形式

### 1. 产品截图解读

适合一个界面就能说明结果的内容。

结构：

1. 封面：人物场景或结果。
2. 产品界面全貌。
3. 放大一个关键区域。
4. 解释这个区域解决什么问题。
5. 展示结果怎样继续使用。
6. 结尾带出产品名称和用途。

### 2. 前后对比组图

结构：

1. 封面：前后变化。
2. 使用前的材料或流程。
3. 原来的麻烦。
4. 产品中的关键操作。
5. 使用后的结果。
6. 结果细节。
7. 完整对比。
8. 产品说明。

### 3. 教程型轮播图

结构：

1. 任务和最终成果。
2. 开始前需要准备什么。
3. 第一步。
4. 第二步。
5. 第三步。
6. 容易出错的地方。
7. 最终结果。
8. 总结和产品出现方式。

### 4. 购买选择组图

结构：

1. 潜在客户正在纠结的问题。
2. 常见做法。
3. 判断标准。
4. 产品中的真实处理方式。
5. 完整使用画面。
6. 结果和细节。
7. 适合与不适合的人。
8. 产品说明。

### 5. 用户案例组图

结构：

1. 人物或团队和使用时刻。
2. 原来的处理方式。
3. 最麻烦的环节。
4. 开始使用产品。
5. 产品中的关键动作。
6. 结果画面。
7. 结果后来怎样使用。
8. 产品与案例总结。

### 6. 选择与对比图

结构：

1. 一个明确选择题。
2. 判断标准。
3. 第一种做法。
4. 第二种做法。
5. 两者画面对比。
6. 分别适合什么情况。
7. 产品采用了哪种思路。
8. 总结。

### 7. 长文或深度图文

适合复杂产品、购买决策和 ToB 案例。

结构：

```text
具体场景
问题怎样发生
原来的流程
产品怎样处理
结果和细节
选择标准或用户故事
适合怎样使用
产品总结
```

## 二、标题系统

每篇图文至少给三个标题方向，三个都必须达到可直接发布的自媒体获客标准：

### 结果型

直接说最终发生的变化。

### 问题型

从目标用户熟悉的麻烦开始。

### 使用者型

从目标用户正在经历的具体时刻、动作、挑战或选择开始。

标题要包含具体人物、任务、变化或冲突，避免只有“AI工具”“效率神器”“重磅上线”这类空词。

国内图文的三个标题要有明显差异，全部使用具体人物、痛点、动作、数字、矛盾、悬念或可见结果建立阅读理由。不能用一个自媒体标题搭配两个报告式备选标题。标题承诺必须在逐页内容中被画面兑现。

## 三、封面系统

封面只表达一个核心内容。

需要确定：

- 主标题。
- 一句补充信息。
- 主视觉是产品界面、结果、人物还是前后对比。
- 产品 Logo 是否出现。
- 系列名称是否出现。
- 背景和品牌色。
- 用户第一眼应该看到哪里。

### 产品亮点封面

优先使用结果画面、前后对比或产品关键界面。

### 选择指南封面

优先使用目标客户正在比较的两个状态、关键问题或真实产品证据。

### 用户案例封面

优先使用人物身份、任务和结果，不要用一张无关人物素材代替案例主体。

## 四、页面写法

每一页只承担一个作用：

- 建立场景。
- 展示问题。
- 解释动作。
- 放大结果。
- 补充细节。
- 推进故事。
- 总结产品。

检查页序时，删除重复表达同一个意思的页面。

## 五、截图和结果图

需要规划：

- 截图来自哪个产品步骤。
- 是否需要裁切或放大。
- 哪一块需要箭头、框线或文字标注。
- 是否需要输入材料与输出结果同屏。
- 是否需要旧版本和新版本同屏。
- 是否需要人物使用场景照片。
- 是否需要流程图或结构图。

产品功能依靠界面展示时，主画面优先使用实际产品截图。概念插画负责气氛和理解，产品截图负责说明功能。

## 六、正文与配文

正文顺序可以是：

1. 一个具体时刻。
2. 为什么这个时刻麻烦。
3. 产品做了什么。
4. 画面中的结果。
5. 结果里最值得看的细节。
6. 谁适合这样使用。
7. 自然带出产品名称。

选择指南正文增加：客户顾虑、判断标准、产品证据和适用边界。

案例正文增加：人物背景、原流程、使用过程和结果去向。

## 七、完整图文卡

每套图文方案交付：

```text
内容角度：
目标人物和场景：
三个标题：
封面文案：
封面画面：
页数：
逐页文案：
逐页画面：
所需产品截图：
所需结果图：
所需补充视觉：
完整正文或配文：
一句内容描述：
标签 Tags：
结尾产品说明：
可拆出的短图文：
```

Tags 默认提供六到十二个，覆盖受众、场景、品类、内容主题和产品类型。标签必须与正文实际内容一致，不使用无关热词，不把同一组 Tags 原样复制到所有平台。

国内图文封面默认比例为 `2:3` 竖版，主标题直接进入画面并与文章主标题一致。桌面 HTML 报告默认一行三张封面卡，平板一行两张，手机一行一张。

## 八、六套图文的内容分布

完整推广方案默认从以下类型中选择六套：

- 一套核心产品亮点。
- 一套使用前后对比。
- 一套教程或工作方法。
- 一套购买选择或常见顾虑。
- 一套用户案例、创始人实测或样例场景。
- 一套产品观点、对比或常见疑问。

产品特点明显时可以调整分布，但六套内容不能都讲同一个功能，也不能把开发过程混入默认获客案例。
